## Choix de langue

Les cinq dépôts très étoilés ci-dessus utilisent l'anglais comme langue principale de leur README. Des dépôts francophones existent toutefois, notamment [ddaanet/skills](https://github.com/ddaanet/skills), [etalab-ia/skills](https://github.com/etalab-ia/skills) et [swiss/swiss-federal-writing-guidelines](https://github.com/swiss/swiss-federal-writing-guidelines). Certains projets proposent aussi un fichier français séparé, comme [jtydhr88/screenwriting-skills](https://github.com/jtydhr88/screenwriting-skills/blob/main/README_FR.md).

La décision retenue est donc un README bilingue avec l'anglais en premier pour la découverte internationale, puis une version française complète pour le public naturel de l'auteur. Le fichier `SKILL.md` reste unique afin d'éviter deux implémentations susceptibles de diverger.

## Structure et découverte

- [Agent Skills : spécification](https://agentskills.io/specification) : SKILL.md, nom, description, références relatives et ressources facultatives
- [SkillsMP : présentation](https://skillsmp.com/about) : collecte de SKILL.md issus de dépôts publics et exposition des créateurs et sources
- [Skills CLI](https://skills.sh/docs/cli) : syntaxe d’installation depuis un dépôt
- [Skills.sh : documentation](https://skills.sh/docs) : classement fondé sur des installations observées, distinct des étoiles GitHub
- [GitHub : topics](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/classifying-your-repository-with-topics) : classification aidant la découverte
- [GitHub : archives sources](https://docs.github.com/en/repositories/working-with-files/using-files/downloading-source-code-archives) : téléchargements ZIP de branches, versions et commits

Ni l’indexation dans un annuaire, ni son calendrier, ni un badge d’approbation ne sont garantis par la présence de ces fichiers.
